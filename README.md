# 영수증 스캔 PWA

영수증을 구분(경비·접대비·회의비·출장비)별로 촬영해 보관함에 모으고, 청구할 때 A4 청구본 PDF로 만들어 본인 Google Drive에 저장하는 앱입니다.

## 진행 상황

- [x] 2단계: 뼈대 + 홈 껍데기 (하단 메뉴 홈·보관함·예산, 홈 구분 카드 4개 — 합계만)
- [ ] 이후 단계: 설계서의 개발 순서를 따릅니다

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 첫 화면 틀 |
| `css/app.css` | 디자인 |
| `js/app.js` | 화면 전환·홈 화면 |
| `manifest.webmanifest` | 홈 화면에 앱으로 추가할 때 이름·아이콘 |
| `sw.js` | 오프라인 캐시 |
| `icons/` | 앱 아이콘 |

## 업데이트할 때

`css/app.css`, `js/app.js`를 고치면 `index.html`의 `?v=숫자`와 `sw.js`의 `CACHE` 이름 숫자를 함께 올립니다. 그래야 폰에 설치된 앱이 새 버전을 받습니다.
